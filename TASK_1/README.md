# DevSoc AI/ML Project

## About
This project uses the Google Gemini API to process questions from a text file and save the answers in a JSON file using Python.

## Files
- `main.py` - Python code that connects to the Gemini API.
- `text.txt` - Contains the input questions.
- `responses.json` - Stores the generated answers.
- `requirements.txt` - Contains the required Python libraries.

## Requirements
- Python
- Google Gemini API key
- Internet connection

## How to Run

1. Install the required library:

   ```bash
   pip install requests
   ```

2. Run the Python program:

   ```bash
   python main.py
   ```

3. Enter your Gemini API key when prompted.

4. The generated answers will be saved in `responses.json`.

## Technologies Used
- Python
- Google Gemini API
- Requests
- JSON

## Note
Keep your API key private. Do not upload it to GitHub or include it in your submission.
